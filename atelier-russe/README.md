# Русская мастерская — Atelier russe

Atelier d’apprentissage du russe en une seule page HTML, inspiré de la culture russe (vermillon, or, cobalt de Gjel).

## Contenu
- Alphabet cyrillique, translittération (FR/EN), clavier cyrillique à l’écran
- Vocabulaire, grammaire, nombres, écoute (synthèse vocale ru-RU)
- Cartes à répétition espacée (boîtes de Leitner), carnet « Mes erreurs »
- Objectif quotidien et série de jours
- Scènes jouées et examen de niveau chronométré

## Utilisation
Ouvrir `index.html` dans un navigateur, ou via GitHub Pages :
**Settings → Pages → Source : Deploy from a branch → `main` / `(root)`**.

La progression est enregistrée localement dans le navigateur (localStorage).
